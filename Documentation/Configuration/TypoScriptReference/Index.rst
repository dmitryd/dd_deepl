TypoScript reference
====================

..  deprecated:: 14.0
    TypoScript configuration is only used when the extension configuration
    option :php:`configurationSource` is set to
    :php:`legacyTypoScript`. Legacy mode emits a deprecation warning.
    There is no automatic fallback from site configuration to TypoScript.

..  warning::
    Use :ref:`configuration` for new installations and
    :ref:`migration` for existing TypoScript configuration.
